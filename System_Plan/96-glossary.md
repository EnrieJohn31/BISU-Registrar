# Glossary

[Back to index](index.md)

Updated: 2026-10-17. Terms and abbreviations used across the plan.

| Term | Meaning in this plan |
|---|---|
| ARTA | Anti-Red Tape Authority; oversees government service standards, including the Citizen's Charter and Client Satisfaction Measurement |
| Assessment | The authoritative amount a client owes for a request, created at Registrar endorsement from the approved fee version |
| Assisted intake | A staff member submits a request on behalf of a client at the counter, using the same rules as the portal |
| Audit event | A stored record of who did what, when, to which record, and why |
| BAC | Bids and Awards Committee; handles government procurement |
| CAV | Certification, Authentication and Verification of academic records |
| Citizen's Charter | The published list of a government office's services, steps, requirements, fees and processing times, required under RA 11032 |
| Clearance (financial) | In this plan: Cashier has verified full payment, so the request may continue |
| Clearance (office) | A student's sign-off from other offices (for example accounting or library), checked by Registrar staff as a requirement |
| COA | Commission on Audit |
| CSM | Client Satisfaction Measurement; ARTA's harmonized client feedback survey |
| Cutover | Switching from the paper process to the system as the primary record (Part 14) |
| DPO | Data Protection Officer of the university |
| DPA | Data Privacy Act of 2012 (RA 10173) |
| Hold | A blocking flag (payment dispute or record issue) that stops approval or release until resolved |
| Idempotency key | A token that makes a repeated submit or click produce one result, not duplicates |
| Inertia | The library connecting Laravel controllers to Vue pages without a separate API |
| Kiosk | A shared campus device for self-service intake, with session reset between clients |
| LAN | The BISU campus local network; "online" in this plan means access through it |
| MIS | Campus Management Information Systems / IT office |
| NPC | National Privacy Commission |
| OR | Official Receipt issued by the Cashier |
| PhilGEPS | Philippine Government Electronic Procurement System |
| PIA | Privacy Impact Assessment |
| PWD | Person with disability |
| RCD | Report of Collections and Deposits, the Cashier's official collection report |
| Reference | The public, non-guessable request number a client uses to track a request |
| Release | The recorded handover of a completed document to the verified claimant |
| Service calendar | Working days, holidays and suspensions used for queues and working-day turnaround |
| Snapshot | A copy of service, fee or document inputs saved at a transaction step so later edits don't change history |
| SPA | Special Power of Attorney, used for representative claims |
| Staging | A campus test environment that mirrors production but holds no live transactions |
| Supplier | A business supplying goods or services to the Registrar's Office (Part 16) |
| TOR | Transcript of Records |
| UAT | User acceptance testing by the offices |
| Wayfinder | Laravel tool that generates typed frontend route helpers |
| Working day | A service-calendar day the office is open; Citizen's Charter processing times count working days |
