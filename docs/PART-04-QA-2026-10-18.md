## Findings and fixes

| Finding | Reproduction | Resulting behavior |
|---|---|---|
| Older profile history was inaccessible | Create a profile and make 50 corrections. The detail response stopped at the newest 50 revisions; creation was unreachable | Server pagination returns 50 revisions per page, newest first. The shared Vue pagination controls reach older pages and link to the history section. Queries remain scoped to the selected profile |
| Client details could escape through a free-text reason | Include a synthetic client name and full ID in a reason. The entire reason was copied into the general audit event, readable by administrators and Registrar supervisors who cannot open client records | Every client mutation stores the original reason in restricted revision history. General audit events contain a fixed reason referencing the revision, alongside the existing action, actor, office, version and masked identifiers |

Both regression tests failed before the fixes and passed afterwards. An independent code review found no remaining issue in these changes.
